# Countdown

A personal tracker: countdowns to the dates that matter, plus daily steps, calories, workouts and skincare/hair routines, shown as a planner-style habit wheel. It runs as one web app — in a PC browser and installed on the iPhone home screen. Steps and workouts come from Apple Health via an iPhone Shortcut.

**Status:** design. See the [design spec](docs/superpowers/specs/2026-10-19-countdown-tracker-design.md).
